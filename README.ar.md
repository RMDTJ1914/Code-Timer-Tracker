## 🌟 نظرة عامة ورؤية المنتج

**Code Timer Tracker** هو نظام برمجي متكامل تم بناؤه خصيصاً لمطوري البرمجيات وهندسة النظم للإجابة الدقيقة على الأسئلة الجوهرية حول الوقت والإنتاجية:

- *كم من الوقت الفعلي قضيته اليوم في كتابة وبرمجة الأكواد مقابل فترات الانقطاع؟*
- *ما هي المستودعات البرمجية والمشاريع التي استحوذت على الحصة الأكبر من ساعات العمل هذا الأسبوع؟*
- *هل تقديراتي الزمنية الأولية للمهام البرمجية تتطابق مع مدة التنفيذ الفعلي المسجلة؟*
- *ما هو معدل استمرارية الأيام النشطة (Active Streak) ومؤشر تسارع التركيز؟*
- *كيف أقوم بتتبع ساعات العمل المدفوعة وتصدير تقارير محاسبية نظيفة دون انتهاك الخصوصية؟*

تم تصميم التطبيق بمعمارية **محلية بالكامل (Local-First Architecture)**؛ جميع السجلات والبيانات تظل محفوظة بأمان داخل متصفحك المحلي دون أي خوادم تتبع خارجي أو جمع لبيانات الأكواد.

## ✨ القدرات والميزات الهندسية الأساسية

### 1. محرك توقيت عالي الدقة (High-Precision Time Engine)
- **حساب زمني دقيق عبر الفروق الزمنية (Delta Epoch Timestamps):** يتم احتساب الوقت المنقضي بطرح الطابع الزمني للبداية مع خصم فترات الإيقاف المؤقت بدقة متناهية (`now - startTime - pausedDuration`)، مما يقضي تماماً على أي انحراف في التوقيت أو بطء ناتج عن دخول تبويب المتصفح في وضع الخمول.
- **استمرارية الجلسات والتعافي من الانهيار:** حفظ متزامن وفوري لحالة الجلسة النشطة في التخزين المحلي؛ إعادة تحميل الصفحة أو إغلاق المتصفح واستئنافه يسترجع المؤقت بنفس اللحظة دون فقدان ثانية واحدة.
- **تتبع فترات الإيقاف التراكمية:** إدارة دقيقة لفترات التوقف المؤقت المتعددة مع عرض حي لزمن التوقف.
- **مؤشر المؤقت العالمي (Global Header Pill):** متابعة وقت الجلسة النشطة وأزرار التحكم السريع من أي صفحة داخل الأداة.
- **تسجيل الجلسات السابقة يدوياً:** إمكانية إضافة ساعات العمل التي تمت دون اتصال، مع تحديد التاريخ والمدة وحالة الدفع والوسوم والملاحظات.
- **تعديل السجلات وحذفها:** تصحيح تواريخ ومدد الجلسات السابقة والمشاريع المرتبطة بها مع إعادة احتساب فورية للإحصائيات.

### 2. إدارة مشاريع ومهام المطورين (Projects & Tasks)
- **سياق المستودعات البرمجية:** ربط الجلسات بالمشاريع البرمجية، شارات حزمة التقنيات المستخدمة (مثل: React, Node, Python, Docker)، الأجر بالساعة، والتصنيف البرمجي.
- **تتبع على مستوى المهام والتذاكر:** تعيين أولويات المهام (`منخفضة`، `متوسطة`، `عالية`، `حرجة`)، وحالات الإنجاز (`قيد الانتظار`، `قيد التنفيذ`، `مكتملة`)، مع التقدير الزمني بالدقائق ومواعيد التسليم.
- **بدء فوري بنقرة واحدة:** إطلاق مؤقت التتبع مباشرة من بطاقة أي مشروع أو سطر مهمة.
- **نظام الأرشفة النظيف:** أرشفة المستودعات المكتملة للحفاظ على تنظيم بيئة العمل مع الإبقاء على كافة سجلاتها التاريخية في التقارير.

### 3. تجربة خاصة ومستقلة بالكامل للهواتف الذكية (Dedicated Mobile Experience)
- **قفل التمرير الأفقي ومنع الاهتزاز (Zero Horizontal Scroll Lock):** تصميم متوافق ومخصص بالكامل لشاشات الهواتف من مقاس 320px فما فوق مع منع تمايل الصفحة أو الارتداد اللمسي نهائياً.
- **قمرة قيادة سفلية مخصصة (Mobile Bottom Cockpit):** شريط تنقل سفلي سريع مع أزرار لمس مريحة (الرئيسية، المؤقت، المشاريع، الجلسات، المزيد).
- **مشغل عائم ذكي للمؤقت:** شريط مصغر يظهر فقط عند وجود مؤقت نشط أثناء التصفح في بقية الصفحات، مع إخفائه بذكاء داخل صفحة المؤقت لمنع الازدحام.
- **موجز الكروت المتتالي للجلسات (Cards Feed):** استبدال الجداول التقليدية بكروت تفاعلية أنيقة مصممة لتجربة اللمس على شاشات الهواتف.

### 4. تطبيق أندرويد مستقل ويعمل 100% بدون إنترنت (v2.4.3)
- **ملف تثبيت رسمي وموقع رقمياً (Signed Release APK):** تطبيق أندرويد أصيل وخفيف للغاية بحجم 1.7 ميجابايت فقط (`code-timer-tracker.apk`).
- **يعمل بالكامل دون أي اتصال بالإنترنت (Zero Internet Required):** لا يعتمد على أي سيرفرات أو شبكات CDN خارجية؛ تم تضمين محرك أيقونات FontAwesome 6 بتقنية SVG المتجهية الأصلية (المضمونة للظهور في كافة أجهزة الأندرويد وWebViews) ومكتبة Chart.js التفاعلية محلياً بالكامل.
- **تخزين فوري وآمن محلياً:** يتم حفظ جميع الجلسات والمشاريع في ذاكرة الهاتف الداخلية مع إمكانية التصدير والنسخ الاحتياطي بأي وقت.

### 5. تحليلات ورسوم بيانية حقيقية 100% (Genuine Analytics)
محسوبة بالكامل من جلساتك الفعلية المسجلة (خالية تماماً من البيانات الوهمية):
- **محدد الفترات التفاعلي:** تصنيف الإحصائيات بحسب: *هذا الأسبوع*، *هذا الشهر*، *آخر 30 يوماً*، أو *كامل الوقت*.
- **توزيع الوقت حسب المشروع:** رسم بياني دائري يوضح ساعات العمل الموزعة على المستودعات.
- **حجم البرمجة اليومي:** رسم بياني عمودي لساعات البرمجة يوماً بيوم.
- **منحنى التركيز التراكمي:** رسم خطي يوضح وتيرة وتسارع ساعات البرمجة والتركيز.
- **تحليل مجالات العمل والتقنيات:** توزيع زمني مرئي لمهارات الواجهة الأمامية، الخلفية، والعمليات وغيرها.
- **مقاييس الإنتاجية الرئيسية:** إجمالي ساعات العمل، متوسط مدة الجلسة، عدد الجلسات، المستحقات المدفوعة، والمشروع الأكثر نشاطاً.

### 6. أدوات وسير عمل المطورين (Developer Workflows)
- **لوحة الأوامر السريعة (`Ctrl+K` / `Cmd+K`):** بحث وتنفيذ فوري لجميع عمليات التنقل، بدء المؤقت، تصدير البيانات، وتغيير الإعدادات.
- **وضع التركيز الكامل الخالي من المشتتات (`Ctrl+B`):** شاشة كاملة بمؤقت رقمي كبير مع تفاصيل المهمة دون أي عناصر جانبية مشتتة.
- **مساعد فترات التركيز (بومودورو):** مؤقت عمل واستراحات خفيف مدمج مع نغمات صوتية مركبة برمجياً تعمل دون إيقاف جلسة التتبع الرئيسية.
- **تصدير بصيغة CSV المتوافقة مع RFC 4180:** تصدير معتمد بترميز UTF-8 مع تضمين BOM لضمان العرض السليم باللغة العربية داخل Excel وGoogle Sheets.
- **نسخ احتياطي واستعادة آمنة عبر JSON:** تصدير كامل لبيانات مساحة العمل مع التحقق البرمجي من هيكل البيانات وخيارات الاستبدال أو الدمج.
- **دعم ثنائي كامل للغتين العربية والإنجليزية:** واجهة تفاعلية كاملة مع قلب الاتجاه الطبيعي RTL وخط "Cairo" الاحترافي.

## ⌨️ اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
| :--- | :--- |
| `Space` | بدء أو إيقاف مؤقت أو استئناف الجلسة النشطة (خارج حقول الكتابة) |
| `Ctrl + Shift + S` | إنهاء وحفظ الجلسة النشطة في السجل |
| `Ctrl + K` / `Cmd + K` | فتح لوحة الأوامر السريعة (Command Palette) |
| `Ctrl + B` / `Cmd + B` | تفعيل أو إغلاق وضع التركيز الكامل (Focus Mode) |
| `Ctrl + 1` | الانتقال إلى لوحة المؤشرات (Dashboard) |
| `Ctrl + 2` | الانتقال إلى منصة المؤقت الحي (Timer Console) |
| `Ctrl + 3` | الانتقال إلى المشاريع والمهام (Projects & Tasks) |
| `Ctrl + 4` | الانتقال إلى سجل الجلسات (Sessions History) |
| `Ctrl + 5` | الانتقال إلى التحليلات والتقارير (Productivity Analytics) |
| `Escape` | إغلاق النوافذ المنبثقة، لوحة الأوامر، أو الخروج من وضع التركيز |

## 🛠️ البنية البرمجية والتقنيات المستخدمة

- **الواجهة الأساسية:** Vanilla HTML5، CSS3 الحديثة، JavaScript ES2022.
- **الرسوم البيانية:** مكتبة Chart.js، مع أيقونات Font Awesome 6.
- **النظام الصوتي:** Web Audio API Procedural Synthesizer (مركب صوتي بدون ملفات صوت خارجية ويعمل بالكامل Offline).
- **التخزين:** LocalStorage في المتصفح مع ترقية آلية لهيكل البيانات (Automated Schema Migration).
- **الاختبارات:** بيئة الاختبارات المدمجة في Node.js (`node --test tests/test_engine.js`).

## 🚀 البدء والتشغيل المحلي

التطبيق يعمل بالكامل من جانب العميل (Client-Side) ولا يتطلب أي إعداد خادم أو خادم قواعد بيانات.

### التشغيل المحلي:
1. استنساخ المستودع:
   ```bash
   git clone https://github.com/mokashreef/Code-Timer-Tracker.git
   cd Code-Timer-Tracker
   ```
2. فتح ملف `index.html` في أي متصفح حديث، أو تشغيل خادم محلي خفيف:
   ```bash
   npx serve .
   ```

### تشغيل الاختبارات البرمجية التلقائية:
لتشغيل حزمة الاختبارات التي تفحص عمليات التوقيت، تصدير CSV، احتساب الاستمرارية، وهيكل النسخ الاحتياطي:
```bash
npm test
```
